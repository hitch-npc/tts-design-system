# Заставка главной — пакет для фронтенда

`tts-intro.js` — заставка целиком: стили, разметка и логика в одном файле, внешних зависимостей нет.
`index.html` — живой пример и документация: подключение, параметры, когда играет, ход, требования к странице, доступность.

Коротко:

- Скрипт ставится сразу после `<body>`. Запуск — `TTSIntro.start({ images, fallbacks, poster, tickets, meta, onReveal, onPoster })`.
- Первый визит в браузере — длинная версия, около 5–5,5 с. Новый визит — обычная, около 3 с, идёт за реальной загрузкой.
  Повторные загрузки в той же вкладке — без заставки.
- Свет — «Рампа». Надпись: «Ticket to Show» — Cormorant Garamond italic 400, остальное — Manrope 200.
  Размер надписи считает CSS от окна.
- После заставки страница всегда стоит в самом верху. «К билетам» прокручивает к блоку `tickets`.
- Нужны ядро R14 (`ds-core-r14.css`) и шрифты из строки в `index.html`.
- Для проверки: `?intro=0`, `?intro=long`, `?intro=short`, `TTSIntro.reset()` в консоли.
