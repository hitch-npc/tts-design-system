# TTS — личный кабинет (профиль): пакет для фронтенда и бэкенда

Основа — DS TTS R14. Состояние на 26 октября 2026. Задача из трекера: вход по коду или паролю, профиль,
история покупок, избранное, смена данных по именным билетам, возврат заказа.

- **Живой макет:** `site/account.html` — кнопка «Открыть живой макет» на витрине пакета и в спецификации. Внизу экрана — переключатель
  состояний макета: «Обычное», «Много событий», «Пусто», «Не вошёл». Кнопка темы в шапке переключает тёмную и светлую.
- **Презентация с кадрами:** `index.html` в этой папке.
- **Спецификация:** `spec.html` — этот README в оформленном виде; собирается из него (`npm run build`).
- **Кадры:** `screens/` — десктоп 1440, телефон 390, обе темы, ретина 2×.

Компоненты ядра (`ds-core-r14.css`, `ds-core-r14-light.css`, `tokens.json`) этим пакетом **не менялись**: новое живёт в `<style>`
макета. В ядро и редизайн v2 переносится после утверждения макета.

## 1. Вход

- Шаг 1 — почта, кнопка «Получить код». Шаг 2 — «Код отправлен на …», поле на 6 цифр (`autocomplete="one-time-code"`),
  «Отправить ещё раз через 0:59», «Изменить почту». Код действует 10 минут.
- По паролю: почта + пароль, ссылки «Войти по коду» и «Забыли пароль?». «Забыли пароль?» ведёт на вход по коду — отдельного сброса не нужно.
- Профиль создаётся при первой покупке; пароль не обязателен. Если пароля нет, вход только по коду.
- Переход по ссылке «Возврат билетов» из футера без входа — экран входа с текстом про возврат (кадр 16).
- В шапке без входа — «Войти», после входа — «Профиль».

## 2. Шапка профиля

- Надзаголовок «Профиль», имя `.t-h1` (Имя Фамилия из ФИО), данные: почта, телефон, пол, дата рождения.
- Кнопки: «Редактировать профиль», «Сменить пароль», «Мои возвраты N» (N — заявки на рассмотрении).

**Меню профиля в шапке** (кадры 24, 25, m07). Кнопка «Профиль» (на телефоне — иконка) открывает меню:
имя без почты и телефона; «Предстоящие N», «Избранное N», «История покупок», «Мои возвраты N»; под именем — «Редактировать профиль» с карандашом (серое, без подчёркивания);
под линией — «Выйти». «Выйти» завершает сессию и ведёт на экран входа с уведомлением «Вы вышли из профиля».
Гость нажимает «Войти» — меню нет, сразу экран входа.

- **Иконка, «Туман»** — только при наведении и при открытом меню. За иконкой проявляется мягкое пятно: конический градиент
  из жанровых цветов `--blob-core` (синий) и `--blob-purple` (фиолетовый) с серебром, всё разбавлено бело-серым
  (`color-mix` с `--n100`; в светлой теме — пастель, чуть насыщенная `--accent` / `--n400`, серебро `--n800`).
  Размытие 8px, прозрачность .5, перелив по кругу — оборот 3,2 с, «дыхание» масштабом .92–1.06 за 2,4 с.
  Появление 600 мс. В покое иконки без эффекта.
- **Раскрытие:** как окно фильтров — из-под кнопки в 10px, по правому краю, ширина 248px; появление 420 мс
  `cubic-bezier(.16,1,.3,1)` (сдвиг сверху, лёгкий масштаб, шторка `clip-path` сверху вниз), уход 252 мс;
  строки проявляются по очереди с шагом 30 мс.
- Закрывается кликом мимо, `Esc` (фокус возвращается на кнопку), выбором пункта. Стрелки ↑↓ ходят по пунктам.
- При `prefers-reduced-motion` — без анимации и вращения.
- «Редактировать профиль»: ФИО, почта, пол (Не указан / Мужской / Женский), дата рождения `ДД.ММ.ГГГГ`.
  Если почта изменена — обязательное поле «Пароль»; без него форма не сохраняется (поле с ошибкой).
- «Сменить пароль»: текущий, новый (не меньше 8 символов), повтор.
- Аватара нет — отложен до загрузки фото на бэкенде.
- Вкладки «Предстоящие», «Избранное», «История покупок»: если не помещаются (телефон) — лента с прокруткой;
  край, за которым есть ещё вкладки, растворяется, выбранная вкладка прокручивается в видимую часть.

## 3. Предстоящие

- **Показ = событие + площадка + зал + дата и время.** Заказы на один показ — в одной карточке («3 билета · 2 заказа»).
  Если отличается хоть зал — отдельные карточки, даже при одинаковом названии.
- Карточка: афиша 16:10, надзаголовком дата «СБ · 7 НОЯБРЯ · 19:00» (стиль `.t-caption`), название Cormorant,
  площадка полужирным `--n200` и зал `--n400`, число билетов. Справа «Скачать» (билеты PDF) и шеврон раскрытия.
- Раскрытая карточка: блок на каждый заказ — номер, дата покупки, число билетов, сумма, «Вернуть заказ»;
  под ним билеты: ряд и место, зона, «На кого билет» (ФИО, документ маской «•••• 5678»), цена.
- **Именной билет** (`named_tickets`): кнопка «Изменить данные» → ФИО, тип документа, номер. Меняется только этот билет.
- **Обычный билет**: строка «На кого билет» не показывается — ФИО есть только у именных. Это же в форме возврата.
  У обычных билетов кнопки нет.
- Заказ с заявкой на возврат «На рассмотрении» — тег вместо «Вернуть заказ», данные не меняются.
- Сортировка — по дате мероприятия. Первые 5 показов, дальше «Показать ещё N».
- Пусто: «Предстоящих мероприятий нет» + «Перейти к афише» (кадр 17).

## 4. Избранное

- Две полки подряд: «Мероприятия N» и «Площадки N», без фильтра.
- Десктоп: на полке один ряд из трёх, «Все N» раскрывает остальное. Ниже 1080px — лента со свайпом, все карточки сразу,
  следующая выглядывает справа. Кнопка «Все N» есть и здесь: раскрывает ленту в столбец, «Свернуть» возвращает ленту; страница плавно прокручивается так, что вкладки оказываются у верха экрана, — так видно, что карточек больше.
- Карточка мероприятия: афиша, сердце (убрать; в уведомлении — «Вернуть»), дата надзаголовком, название, площадка, «от N ₽», «Билеты».
- Карточка площадки: логотип на плашке (логотипы с tickettoshow.ru — белые SVG, в светлой теме инвертируются), название,
  «N событий в афише», «Афиша площадки».

## 5. История покупок

- Все заказы по дате покупки, новые сверху: дата покупки, номер заказа, сумма; ниже карточка показа (свёрнута).
- Только просмотр: билеты и ФИО видны, менять нельзя (см. открытые вопросы, п. 9).
- **Архивный вид** — у прошедших событий и заказов с возвратом «На рассмотрении» / «Возврат завершён»:
  афиша ч/б и приглушена, рамка пунктиром, текст серый. Будущие заказы и заказ с отклонённым возвратом — обычные.
- Статусы тегами: «Прошло», «Возврат на рассмотрении» (оранжевый), «Возврат отклонён» (красный), «Возврат завершён» (зелёный).

## 6. Возврат

Модалка возврата на текущем сайте заменяется профилем. Ссылка «Возврат билетов» в футере ведёт в «Предстоящие»
с подсказкой: «Возврат теперь оформляется в профиле… — номера билетов и почту вводить не нужно»; в подсказке
ссылка «Условия возврата» раскрывает условия на месте.

- Возврат — **заказом целиком**, не по билету. В заказе — билеты только на один показ.
- Форма «Оформление возврата»: показ, билеты заказа (только просмотр), «Стоимость заказа», причина возврата, «К возврату», комментарий до 500 символов,
  условия возврата (свёрнуты), «Отмена» / «Отправить запрос →».
- После отправки — заявка в «Мои возвраты» со статусом «На рассмотрении», в заказе вместо кнопки — тег.
- Повторная заявка после отказа заменяет прежнюю в списке.
- «Мои возвраты»: две группы. **«На рассмотрении N»** — живые заявки, обычный вид. **«Закрытые N»** — отклонённые
  и завершённые, ниже, с отступом: как архив в истории — без подложки, рамка пунктиром, афиша ч/б, текст серый; цвет тега
  итога остаётся. Строка раскрывается: номер заявки, заказ, билеты, дата, сумма, статус; у отклонённой — ответ поддержки,
  а если показ ещё впереди — кнопка «Подать повторно» (новая заявка заменит отклонённую).
- Счётчик «Мои возвраты N» в профиле и меню — только заявки на рассмотрении; закрытых нет — числа нет.
- Сроки рассмотрения в тексте формы: до 3 рабочих дней.

**Сроки возврата (решение владельца, 26.10.2026).**

- **Время до начала считается точно, в часах:** `starts_at − now`, время сервера, Москва. Не календарными днями:
  показ 27 октября в 19:00, сейчас 25 октября в 12:00 — осталось 55 часов, это уже «меньше 3 суток».
- **«Вернуть заказ» есть до начала события.** После начала кнопки нет, показ уходит в историю.
- **Последние 72 часа** — кнопка остаётся. В шапке заказа серая подпись «Меньше 3 суток до начала»,
  в форме — оранжевое предупреждение: «осталось 2 суток 7 ч» (меньше 48 часов — только часы: «осталось 30 ч»), по общим условиям возврат не делается, при болезни
  или смерти близкого нужны документы (до 7 дней после мероприятия).
- **Причина возврата** — обязательный выбор: «Передумал(а)» (по умолчанию), «Болезнь», «Смерть близкого».
  Для двух последних появляется «Прикрепить документы» (можно прислать позже).
- **«К возврату»** — оценка по общим условиям, только для «Передумал(а)»:

  | До начала | Возврат | Пример, заказ 5 000 ₽ |
  |---|---|---|
  | 240 ч и больше (10 суток) | 100 % − сбор 10 % | 4 500 ₽ |
  | 120–240 ч (5–10 суток) | 50 % − сбор 10 % | 2 000 ₽ |
  | 72–120 ч (3–5 суток) | 30 % − сбор 10 % | 1 000 ₽ |
  | меньше 72 ч | 0 | 0 ₽ |

  Для болезни и смерти близкого вместо суммы — «по документам»: сумму определит поддержка.
  Заявку с суммой 0 ₽ отправить можно — её рассматривает поддержка.

## 7. Поиск в шапке

По образцу раздела «Поиск по афише — подсказки» редизайна v2. Пустое поле — «Часто ищут»; при вводе — группы «События»
(превью 56, название Forum, дата и место, «от N ₽») и «Площадки» (логотип, число событий). Совпадение подсвечено цветом.
Латиница исправляется по раскладке («nt» → «те», строка «Показаны результаты для …»). ↑↓ / Enter / Esc.

## 9. Открытые вопросы

- **Правка из истории покупок.** Сейчас история — только просмотр. Разрешать ли менять ФИО и документ у будущих
  именных билетов прямо из истории, или достаточно вкладки «Предстоящие»?
- **Покупатель без пароля.** Профиль создаётся при покупке без пароля. Сейчас в профиле есть только «Сменить пароль»
  с обязательным текущим паролем, а смена почты требует пароль. Нужно: «Задать пароль» без текущего (с подтверждением
  кодом на почту) и вариант смены почты по коду на старую почту.
- **Номер документа в форме «Изменить данные».** В билете номер скрыт маской «•••• 5678», а в форме подставлен целиком —
  значит, полный номер паспорта приходит в браузер. Варианты: поле пустое, номер вводится заново целиком, текущий
  показан маской в подсказке; или полный номер отдаётся отдельным запросом только при открытии формы. Решение — за
  бэкендом и ответственным за персональные данные.
- **Телефон.** Показан в шапке профиля, но изменить его нельзя — ни в «Редактировать профиль», ни в другом месте.
  Нужна ли смена телефона и с подтверждением ли по СМС?

**Заметка вне задачи.** В футере — «Билеты без кассового сбора», а при возврате удерживается сбор дистрибьютора 10 %.
Покупатель может принять это за противоречие. Формулировки — на стороне владельца оферты.
