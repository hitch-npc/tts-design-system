Usage Rules
✓ Заголовки экрана: 28–34px, weight 800, tracking -0.04em
✓ Тело карточки: 14px/400, строчный 1.4–1.5
✓ Caps-метки: 9–10px, weight 700, letter-spacing 0.10–0.15em, uppercase
✗ Не использовать Inter, Roboto или системные шрифты
✗ Не использовать размеры меньше 10px на мобильных

Tokens / Motion

Анимации

Touch-first: состояния :active вместо :hover. Длительность короче десктопа.

Ease smoothcubic-bezier(0.4,0,0.2,1)
Micro · Interactive120–150ms
Transition · Modal/Sheet250–280ms
Orb · Background22–33s alternate
Touch States (вместо hover)
✓ :active → scale(0.97) или opacity 0.7
✓ touch-action: manipulation на кликабельных
✓ -webkit-tap-highlight-color: transparent
✗ Не использовать translateY(-2px) на мобильных
