Иконки
Стиль: Lucide-style, stroke 1.4, linecap/linejoin round
Размер: 24×24 px в SVG, отображается 16px или 20px в UI
Цвет: через currentColor → адаптируется к теме
Соцсети: Brand filled 48×48 (Instagram, YouTube, Telegram, VK, TikTok)
Логотип: только SVG из tts-logo.svg. Никогда текстом.
Запреты
✗ Никогда не хардкодить цвета и шрифты — только через CSS-переменные
✗ border-radius > 8px в UI-компонентах
✗ font-weight: 300 на Cormorant
✗ --accent на декоративных элементах
✗ --premium декоративно (только Premium-блоки)
✗ Одно событие → несколько карточек в афише
✓ Всегда preconnect для Google Fonts
✓ Backdrop-filter с webkit-префиксом
✓ color-mix() для полупрозрачных фонов
