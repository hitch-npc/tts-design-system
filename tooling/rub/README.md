# Знак ₽ — глиф

`rub.woff2` — подмножество Source Serif 4 из одного символа U+20BD (1 КБ), SIL Open Font License 1.1, © Adobe.
Получен из Google Fonts запросом `family=Source+Serif+4:wght@400&text=₽`.

`index.mjs` собирает из него блок `@font-face` (base64). Расставляет блок `tooling/build-rub.mjs`; подробности — `tooling/README.md`, раздел «Знак ₽».
