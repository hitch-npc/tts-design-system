## 1. Карточка события

### 1.1 Решение

Карточка остаётся такой, как в ядре: название — ровно две строки (`line-clamp: 2` + `min-height` под две строки),
площадка — одна строка с многоточием. Под названием в одну строку остаётся пустая строка 26 px — это принято осознанно.

Причина — решение владельца: текущая карточка читается легче всего. Замер показал, что цена держит строку ряда
и без резерва (расхождение 0 px), поэтому резерв теперь держится на читаемости, а не на выравнивании цены.

### 1.2 Что сравнивали

Стенд `lab-card.html`: шесть вариантов × три набора названий × ширины 375 / 768 / 1440 × две темы. Метрики снимаются
автоматически. Цифры ниже — ширина 1440, тёмная тема.

| Вариант | Высота, все названия короткие | Пустота, все короткие | Пустота, смешанный ряд | Расхождение цен в ряду | Итог |
|---|---|---|---|---|---|
| V1 · как в ядре, резерв двух строк | 422 px | 26 px | 26 px | 0 px | **Выбран** |
| V2 · резерв снят, место уходит к разделителю | 398 px | 1 px | 26 px | 0 px | Отклонён |
| V3 · V2 + `subgrid`, общие линии ряда | 398 px | 1 px | 26 px | 0 px | Отклонён |
| V4 · V3 с центровкой текста | 398 px | 1 px | 26 px | 0 px | Отклонён |
| V5 · название на обложке | 376 px | 0 px | 0 px | 0 px | Отложен: нужны реальные обложки |
| V6 · карточка по высоте текста, ряд по верхнему краю | 398–422 px | 1 px | 1 px | 26 px | Отклонён: цены на разной высоте, нижний край рваный |

### 1.3 Что важно знать

- Название длиннее двух строк обрезается многоточием. «Квартет И + Моральный кодекс «Песни и письма мужчин среднего
  возраста»» теряет хвост. Условие пересмотра в №23 прежнее: отдельное поле под программу.
- Текст карточки — по левому краю. Центровка отклонена: рваный край с обеих сторон, цены не читаются столбцом.
- Состояния события (распродано, отменено, перенесено, мало мест, скоро в продаже, бесплатно) не проектировались —
  данных нет. Место под них есть: `.cover-tag` слева вверху и теги `.tag-orange` / `.tag-green`.
- Предложение, в стенде не показано: правый слот футера карточки — время сеанса для одной даты или «ещё N дат»
  для нескольких. Новых полей не нужно, это уже есть в данных.

## 2. Лоадеры и ожидание (P0 для схемы зала)

### 2.1 Что есть сейчас

- В ядре: `.skeleton` (пульс 1,8 с) и `.event-card-skeleton`. Спиннера нет.
- Состояния «кнопка ждёт ответа» нет. Есть только `.btn:disabled` — серая кнопка; как ожидание она выглядит выключенной.
- В новой схеме зала выбор места, удаление из панели, «Сбросить выбор» и «Купить билеты» мгновенные. Ожидание и ошибки
  не нарисованы.

### 2.2 Принципы

1. **Порог 300 мс.** Быстрее ничего не показываем, чтобы не мигало. Показали — держим не меньше 500 мс.
   Цифры стартовые, нужны реальные времена ответа билетной системы.
2. **Оптимистично, где откат дёшев.** Выбор и снятие места: вид меняется сразу, место и строка в панели «ждут»;
   при ошибке — откат с пояснением.
3. **Пессимистично, где ошибка дорога.** «Купить», «Оплатить», «Подтвердить»: кнопка в ожидании, повторное нажатие невозможно.
4. **Ожидание не равно «выключено».** Кнопка сохраняет цвет и ширину, подпись скрыта, по центру кольцо 14 px.
   Серая `:disabled` остаётся для «нельзя нажать».
5. **Индикатор рядом с тем, что ждёт:** на месте, в строке, на кнопке. Глобальных полос загрузки нет.
6. **Ошибка = состояние в элементе + `toast-error` + способ повторить.** Без модальных окон.
7. **Доступность:** `aria-busy` на ждущем элементе, `aria-live="polite"` для сообщений. При `prefers-reduced-motion`
   анимации выключаются, остаётся статичный знак.

### 2.4 Компоненты — кандидаты в ядро

В ядро пока не внесены. Цвета и тайминги — только токены, сырых hex нет. Рабочий код — в `lab-loaders.html`,
блок «Предлагаемые добавки в ядро».

```css
@keyframes tts-spin  { to { transform: rotate(360deg) } }
@keyframes tts-ring  { /* кольцо --seat-sel расходится от 0 до 6px и гаснет */ }
@keyframes tts-sweep { 0% { transform: translateX(-100%) } 100% { transform: translateX(100%) } }

/* Кольцо 14px, цвет наследуется */
.spinner { display: inline-block; width: 14px; height: 14px; border: 1.5px solid currentColor;
           border-right-color: transparent; border-radius: 50%; animation: tts-spin .7s linear infinite; }

/* Кнопка в ожидании: ширина и цвет прежние, подпись скрыта, по центру кольцо.
   Подпись кнопки должна быть обёрнута в элемент (<span>), иначе скрыть её нечем. */
.btn.is-loading { position: relative; pointer-events: none; cursor: progress; }
.btn.is-loading > * { visibility: hidden; }
.btn.is-loading::after { content: ""; position: absolute; left: 50%; top: 50%; width: 14px; height: 14px;
                         margin: -7px 0 0 -7px; border: 1.5px solid currentColor; border-right-color: transparent;
                         border-radius: 50%; animation: tts-spin .7s linear infinite; }

/* Место ждёт ответа: кольцо --seat-sel с пульсом 0,9 с, клик заблокирован */
.smap-dot.smap-dot-pending { cursor: progress; pointer-events: none; animation: tts-ring .9s ease-out infinite; }

/* Строка выбранного места в панели */
.tkt.is-pending { /* поля тускнеют до .55, сверху полоса-«волна» --accent, 1,1 с */ }
.tkt.is-fail    { border-color: var(--danger-border); background: var(--danger-bg); }
.tkt .tkt-err   { font-size: 11px; color: var(--danger-text); line-height: 1.5; }

@media (prefers-reduced-motion: reduce) { /* анимаций нет, остаются статичные знаки */ }
```

Разметка кнопки в ожидании:

```html
<button class="btn btn-primary btn-md btn-full is-loading" aria-busy="true"><span>Купить билеты</span></button>
```

### 2.6 Вопросы к разработке

1. Какие реальные времена ответа у удержания места, создания заказа, загрузки схемы?
2. Есть ли таймер резерва места (hold)? Если есть, нужен счётчик в панели и состояние «время вышло».
3. Место удерживается при клике или только при «Купить»? От этого зависит действие №3.
4. Схема своя или виджет билетной системы? В виджете места и панель не кастомизируются.
5. Приходят ли обновления «место купили» в реальном времени без клика пользователя?
6. Имена компонентов на сайте (`event-card-v3`, `cover-v3`, `tag-v3`, `heading-v3`) в DS не найдены.
   В DS это `.event-card`, `.cover-date`, `.tag`, `.t-h1…h3`. Нужно подтвердить соответствие.

### 2.7 Что проверено и что нет

- Проверено на стенде: шесть состояний кнопки, три скорости ответа (0,25 / 1,2 / 4 с), два исхода (успех, сбой сети),

## 3. Страницы разделов

Спектакли, Классика, Концерты, Детям — один шаблон и четыре раскраски. Стенд `lab-sections.html`: четыре раздела,
три ширины, обе темы, состояния «лента / загрузка / пустой раздел».

### 3.1 Шапка

- Не полноэкранная: около 200 px на 1440, лента начинается в первом экране.
- Состав: крошки «Афиша / Раздел», название Cormorant 500 (`clamp` 2,4–4,4 rem), строка «38 событий · ближайшее — 2 июня»,
  приглушённое свечение жанра справа (правило DS «Blob = жанр»).

| Раздел | Свечение (токены) | Метки на карточках |
|---|---|---|
| Спектакли | `--blob-core-cool` + `--blob-mid-cool` | Драма, Комедия |
| Классика | `--blob-purple` + `--blob-mid` | Опера, Балет |
| Концерты | `--blob-core-warm` + `--blob-mid-warm` | Концерт, Джаз |
| Детям | `--blob-core-green` + `--blob-mid-green` | Сказка, Мюзикл |

### 3.2 Лента и месяцы

- Единая сетка `.grid-cards`, сортировка по ближайшей дате. Карточка — как в ядре (п. 1).
- Одно событие — одна карточка. Событие с датами в июле и ноябре стоит только в июльской группе; ноябрь закрывают
  календарь (п. 4) и дата в чипе («5 дат», «5 июля — 28 июля»).
- Разделитель месяца: «Июнь» Cormorant 500 (1,5–2 rem), год `--n500`, справа счётчик «4 события» капсом 10 px,
  снизу линия `--n800`. Отступ перед следующим месяцем — `--section-gap-md` (64 px). Внутри месяца сетка не прерывается.
- Месяц без событий: пунктирная строка «Август 2026 · событий нет», чтобы пропуск в сезоне не выглядел сбоем.
- Заголовок месяца в стенде липкий (`top: 0`). На реальной странице ему нужен отступ сверху, равный высоте меню.

### 3.3 Состояния

- Загрузка: скелет заголовка месяца и четыре скелет-карточки.
- Пустой раздел: «В разделе пока нет событий» + кнопка «Вся афиша» — штатный `.empty-state`.
- «Показать ещё» в стенде — только пример лоадера (п. 2.3, №15). Пагинация, фильтры, таксономия и SEO в пакет не входят.

### 3.4 Что проверено и что нет

- Проверено: Спектакли на 1440 в тёмной теме, Классика на 768, Детям на 375 в светлой; заголовки месяцев, пустой месяц,
  три состояния.
- Не проверено: реальное меню над липким заголовком, длинные названия на 375 в ленте.

## 4. Календарь на главной

### 4.1 Что в макете сейчас

Полоса из 14 дней (на мобильном 7) и кнопка выбора месяца с сеткой: у каждого месяца счётчик событий, месяц без событий
недоступен. Дни без событий приглушены `--n600`. Что происходит при выборе дня, в макете не описано — это и есть задача.

### 4.2 Три поведения

| | A · фильтр афиши на месте | B · раскрытие под полосой | C · переход на страницу дня |
|---|---|---|---|
| Выбор дня | Рамка кобальта у дня, заголовок афиши ниже — «21 июня · 3 события», чип «21 июня ✕» для сброса. Повторный клик снимает выбор | Под полосой раскрывается панель сеансов дня: время, название, площадка, цена, «Билеты». Афиша ниже не меняется | Переход на страницу раздела с `?date=2026-06-02`. На главной ничего не меняется |
| День без событий | Серый, но кликабельный: «21 июня — событий нет», ближайший показ и кнопки «Показать 22 июня», «Вся афиша месяца» | Та же панель с ближайшим днём | Недоступен: серая цифра без плашки, подсказка «Событий нет», `aria-disabled` |
| Плюсы | Контекст не теряется, нет перехода, один механизм с лентой раздела | Покупка короче на шаг | Самый дешёвый; чистый адрес для шеринга |
| Минусы | Нужна фильтрация афиши на клиенте или запрос | Дублирует афишу, на 375 раздувает первый экран | Переход, потеря контекста; пустой день — тупик |
| Стоимость разработки | Средняя | Высокая | Низкая |

### 4.3 Рекомендация

Основной вариант — **A**: пользователь выбирает день, чтобы выбрать спектакль, и остаётся в афише; день без событий
не тупик. B не рекомендуется из-за первого экрана на телефоне. C — разумная первая итерация, если на фильтрацию нет
времени: её можно развернуть в A без смены вида полосы. Решение владельца по календарю ещё не принято.

Общее для всех вариантов:

- плашка под числом у каждого дня с событиями — одной длины, серая; у дня без событий плашки нет;
- кобальтом выделен только сегодняшний день, над ним «СЕГОДНЯ»;
- день — `<button>`, не `<div>`; `aria-label` вида «29 мая, 3 события»;
- выбранный день в адресе (`?date=`) — для шеринга и кнопки «Назад»;
- при смене дня или месяца полоса остаётся, афиша ниже показывает скелет (в стенде — «Имитировать медленный ответ»).

### 4.4 Что проверено и что нет

- Проверено: A и B на 1440 в тёмной теме, C на 375 в светлой.
- Не решено и не проверено: A на мобильном, выбор диапазона дней, листание недель на 375 (в стенде 7 дней без листания),
  стрелки клавиатуры по полосе, пересечение месяцев.
