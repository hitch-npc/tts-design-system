Два состояния

Контур — не в избранном, заливка — в избранном. Подложка та же, что у даты на обложке; кобальт не нужен — это не главное действие карточки.

Гость

Нажатие без входа открывает экран входа; после входа событие сохраняется само, без второго нажатия.

Разметка

Карточка — article, ссылка на событие растянута на всю карточку, кнопка лежит поверх: кнопку нельзя класть внутрь <a>. Подпись для скринридера меняется вместе с состоянием.
