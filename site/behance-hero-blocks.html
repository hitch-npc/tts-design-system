01 — Project

A system
built like
a theatre.

Ticket to Show is a marketplace for theatre, opera, ballet and concerts. The design system gives the product the gravity of a real stage — deep blacks, restrained typography, a single cobalt accent, and atmospheric blobs that encode genre without a single literal illustration.

Across fourteen revisions the system grew from a moodboard into a production-ready foundation: a token layer with full dark / light parity, a component library tuned for mobile-first booking flows, and a set of six anchor screens covering everything from discovery to e-ticket.

02  ·  The Challenge
Context
“

Most ticketing UIs feel like
spreadsheets with a poster glued on top.
We wanted the interface itself
to feel like the room going dark.

The Problem
Ticketing products lean on stock imagery and loud promo banners. The result is visual noise that fights the event itself for attention.
The Goal
A system quiet enough to host any genre — opera, stand-up, indie rock — without re-skinning. One language, many stages.
The Constraint
Mobile-first. Russian-language UI. Booking flow must remain legible at 360px while still feeling editorial.
03 — Four Principles

The system
rests on four ideas.

Each principle is a constraint disguised as a permission. Together they keep the system coherent across fourteen revisions — from the first wireframe to the production release.

Principle 01

Dark
Atmosphere

The interface starts at #0D0D0D — the colour of an auditorium with the houselights down. Everything else is a reaction to that black.

05 — Typography

Four voices,
one programme.

Forum sets the section titles like a playbill. Cormorant Garamond delivers the editorial weight of event names. Manrope runs the UI without raising its voice. Oranienbaum lets numbers ring like a tolled bell.

01 · Display Cormorant Garamond · 400
Aa Bb
The serif that carries event names, hero statements and editorial headlines. Italic forms used for the lyrical accent — never for whole lines.
02 · Section Heads Forum · Regular
Forum
A neoclassical serif used like a programme title. Sets the tone for discovery and navigation without competing with content.
03 · Interface Manrope · 300–700
Manrope
The precision sans that runs every button, label and form field. Weight scales from 300 to 700; tracking widens at micro sizes for breathing room.
04 · Numerals Oranienbaum
1 500 ₽
Reserved exclusively for prices, dates and any numerical accent. Old-style figures lend the system an unmistakable theatrical cadence.
05 · Caption Manrope · 500 · .22em
CAPTION
The micro layer. 10 to 12 pixels, all-caps, generously spaced — a single role: to label the work of the larger typefaces around it.

10 — Signature Pattern

One event,
many stages.

Theatre productions tour. A single show can play three venues across two weeks at six different times. Most ticketing apps solve this by listing the show six times on the discovery wall. The system refuses to.

The rule: one event, one card.

On the discovery wall, every event appears exactly once — no matter how many venues or dates it covers. All the multiplicity is unpacked inside the event page through a single, dedicated component: the session list.

01 · Venue Filter
Inversion chips (ink on ivory) — distinct from the cobalt CTA, so they read as filter, not action.
02 · Date Grouping
Sessions are grouped by date pill; each pill carries day, weekday and a clear count of shows.
03 · Session Row
Time · venue · hall · price. The full information triangle at a single glance.
04 · Selected State
Cobalt border, accent ghost background, price flips to accent. The CTA below activates.
05 · Sold State
No greyed disabled row — a quiet red micro-tag, dignified rather than apologetic.
