# Кадры колоды на главной

Шесть атмосферных кадров сцены (3:4, 600×800, webp): занавес, прожектор, боке, лучи, скрещённые прожекторы, блики.
Нарисованы для макета, это не афиши событий.

`psikhopaty.webp` — афиша спектакля «Психопаты» (1600×1152, 25:18): постер первого экрана и верхняя карточка колоды.
Горизонтальная — на ней видно, как первый экран держит такие афиши: постер берёт пропорции картинки (`--poster-ar` у `.hero2`).

Как заменить на настоящие афиши: положить файлы сюда (от 900 px по высоте; постер первого экрана — от 1600 px по ширине, без полей) и перечислить их в `INTRO_IMAGES`
в `site/home-new.html`. Последний в списке ложится сверху и перелетает в постер первого экрана, поэтому
он же стоит в `.hero2-poster img`.

Публикуются только изображения, на которые есть права: репозиторий публичный.
