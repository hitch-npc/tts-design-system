# packs/custom — выгрузки с изменённым текстом

Здесь лежат наборы, экспортированные из сэндбокса **с текстом, отличным от дефолтного**.
Дефолты сэндбокса: `premiere=ПРЕМЬЕРА, icon=СМОТРЕТЬ, neon=БИЛЕТЫ, border=КУПИТЬ БИЛЕТ,
gloss=PREMIUM, fill=ПРОДАЖА ОТКРЫТА, count=1 500+, countserif=128 400+`.

Файлы кодировал браузер (WebCodecs VP9), а не `render-webm.mjs`, — поэтому побайтово они
не совпадают с `packs/<вариант>/`, даже там, где картинка та же. Исходные `manifest.txt`
из выгрузок сохранены как есть: в них записаны все тексты и цвета на момент экспорта.

| Папка | Лента | Текст | Варианты | Файлов |
|---|---|---|---|---|
| `08-icon-bilety/` | 08 · Icon slide | `icon=БИЛЕТЫ` | alpha-dark, plate-dark | 4 + 4 |
| `12-fill-predprodazha/` | 12 · Fill sweep | `fill=ПРЕДПРОДАЖА ОТКРЫТА` (5 плиток вместо 4) | alpha-dark, plate-dark | 5 + 5 |
| `set-2026-09-08-predprodazha/` | все 12 лент того дня | `fill=ПРЕДПРОДАЖА ОТКРЫТА`, остальное дефолт | plate-dark | 43 |

Про полный набор `set-2026-09-08-predprodazha`: это срез от 8 сентября, там ещё нет лент
13 и 14 (счётчики), а `03-premiere` разрезана на 3 плитки — сейчас она авто-ширины и даёт 4.
Держим как исторический слепок; для новых паков бери `packs/<вариант>/`.

Не тащил сюда выгрузки, где текст дефолтный, — они дублируют `packs/` по содержанию:
`like` (07), `dots emoji` (02), `sofit` (01), `premier` (03), `10-border`, `05-switch`.

## Как повторить любой из этих наборов

Тексты в сэндбоксе → поле «Текст» в карточке ленты, потом:

```bash
node render-webm.mjs --plates off icon      # → packs/alpha-dark/08-icon
node render-webm.mjs icon                   # → packs/plate-dark/08-icon
```

Сэндбокс держит текст в `localStorage`, рендер снимает то, что в нём стоит.
