# TTS — Telegram custom emoji


## Сэндбокс

Открывается двойным кликом, без сервера и без сборки. Работает с любой папки на любом компьютере.
Настройки (текст, цвета, тема, зазор, размер, подложка) пишутся в `localStorage` браузера, где открыт файл.

| Что | Где |
|---|---|
| Текст ленты | поле «Текст» в карточке — ширина ленты пересчитывается под длину строки |
| Число в счётчике | карточки 13 (гротеск) и 14 (Cormorant) — цифры крутятся, знаки и пробелы стоят на месте |
| Цвет сердца | карточка 07 · Like burst |
| Акцент (кобальт) | любая карточка или верхняя панель — меняется во всех лентах сразу |
| Тема | верхняя панель: тёмная / светлая |
| Зазор | 0 (по умолчанию) / 2px (как реально ставит Telegram) / 6px |
| Размер плитки | 34 / 100 / 160 px |
| Подложка | «Есть» / «Прозрачно» — см. ниже |
| Экспорт | «Экспорт .webm» в шапке — все ленты, кнопка в карточке — одна. Кодирует Chrome прямо в браузере, скачивается zip |

### Два режима подложки

- **Есть** — под графикой плитка цвета темы. Фон впечатан в файл, годится только для своей темы чата.
- **Прозрачно** — фона нет, внутренние поля убраны, элемент занимает весь квадрат. Экспорт пишет
  настоящий альфа-канал: цвет и альфа кодируются двумя VP9-потоками, альфа кладётся в `BlockAdditional`,
  дорожка помечается `AlphaMode 1` — то же, что делает ffmpeg. Файл ложится на любой фон, но цвет
  графики остаётся тем, каким его нарисовала тема: светлый набор не читается на светлом чате.

## Реакции (15–25)

Одиночные эмодзи на один слот: их ставят реакцией под пост, склеивать нечего.

| № | Реакция | Что делает |
|---|---|---|
| 15 | Лайк | сердце на месте с первого кадра, раз в цикл — удар и расходящееся кольцо |
| 16 | Маска: комедия ↔ трагедия | венецианская маска-скульптура: рельеф стоит, движется свет; мимика перекидывается на прищуре, в грустной фазе — кобальтовая слеза |
| 17 | Билетик | корешок отделён перфорацией, подрагивает; штрихкод загорается полосами |
| 18 | Глаз-лого | знак из `tts-logo.svg` один в один, моргание маской поверх формы |
| 19–21 | Софит прямо / влево / вправо | разряд лампы и разворот луча; отличается только угол, корпус на месте |
| 22–25 | Возрастной рейтинг 0+ / 12+ / 16+ / 18+ | счётчик serif из ленты 14, свёрнутый в один слот: барабан замкнут — цикл идёт «число → оборот → то же число», «+» подан кобальтом |

Правило у всех одно: **реакция читается уже на первом кадре**. В превью, в поиске и там,
где автоплей выключен, Telegram показывает статичный кадр — поэтому ни одна не начинается с пустоты.

### Возрастной рейтинг (22–25)

Тот же счётчик, что в ленте 14, но собран под одиночный слот — делить «0+» или «18+» на две
плитки незачем, рейтинг всегда читается целиком.

- **Один слот вместо двух-трёх плиток.** В конструкторе это отдельные карточки 22–25, ширина
  фиксирована: `tiles:1`.
- **Cormorant Garamond 600 вместо 500.** На 24 px в строке реакций serif на 500 плывёт, поэтому
  в набор встроенных шрифтов добавлена пара `w:600` (cyrillic + latin) — файл по-прежнему
  работает без интернета.
- **Барабан замкнут.** Колонка начинается и заканчивается на нужной цифре: `число → оборот →
  то же число`. Статичный кадр Telegram показывает готовый рейтинг, а луп сходится без склейки.
- **Общий кегль.** 51 px с подложкой, 63 px без неё — размер подобран по самой широкой метке
  («18+») и одинаков у всех четырёх: рейтинги стоят в ряд и должны быть одного роста.
- **«+» кобальтом**, с коротким отскоком в момент, когда барабан докручивается.

Рендер (те же ключи `rage0 rage12 rage16 rage18`):

```bash
node render-webm.mjs rage0 rage12 rage16 rage18                    # подложка, тёмная  → packs/reactions/plate-dark
node render-webm.mjs --theme light rage0 rage12 rage16 rage18      # подложка, светлая → packs/reactions/plate-light
node render-webm.mjs --plates off rage0 rage12 rage16 rage18       # альфа, тёмная     → packs/reactions/alpha-dark
```

`plate-light` — единственный набор, где лежат только рейтинги: остальные реакции с подложкой
собраны под тёмный чат.

Два уточнения по знаку глаза (18):

- контур не перерисован ни в одной точке — это тот же `path`, вписанный по ширине 88 из 100;
- подсвета за знаком нет намеренно: радужка в знаке — сквозная дырка, свет бил бы через неё
  сплошным синим диском, а на моргании оставлял синее пятно вместо закрытого глаза.

Про маску (16) отдельно — она собрана иначе, чем остальные реакции:

- **Рельеф статичный, движется только свет.** На 100 px мягкие градиенты дороже всего для VP9,
  и всё, что двигается, кодек пересчитывает каждый кадр. Скульптура стоит, цикл несут блик,
  глазницы и слеза — поэтому детализованная маска весит столько же, сколько прежняя штриховая.
- **Светотень собрана из `--premium` (свет) и `--ink` (тень) поверх базы `--fx-fg`.** На ivory-базе
  тёмной темы работает тень, на тёмной базе светлой — блик. Одна композиция даёт мрамор в тёмной
  теме и базальт в светлой, отдельная версия под тему не нужна.
- **Блик с тёмными кромками.** Чисто светлая полоса по ivory-базе не видна вообще; кромки из `--ink`
  превращают её в скольжение отсвета по глянцу и заодно ломают бандинг на градиентах.
- **Резьба вместо орнамента.** Филигрань референса не копируется: пара линий (светлая плюс тёмная
  со сдвигом 0.9) даёт врезанный штрих, который на 24 px схлопывается в фактуру, а силуэт держит форма.
  Орнамент растёт от висков к бровям и стекает на скулу — над лбом он читался как кудри.
- **Кобальт только в глазницах**, и радужка меньше прорези: если залить глазницу целиком, пропадает
  провал. Сама глазница — впадина, поэтому без подложки она уходит в альфу дыркой
  и маска не разваливается.

Софиты 19–21 рассчитаны на ряд: `20` и `21` рядом дают сходящуюся пару, `19` между ними — рампу.

### 13 · Счётчик · 14 · Счётчик serif

Строка разбирается посимвольно: цифра превращается в барабан-одометр, всё остальное стоит на месте.
Правые барабаны прокручивают больше оборотов, поэтому число «набирается» как в счётчике. «+» и «%»
подаются акцентом с отскоком.

В поле можно писать что угодно: `1 500+`, `+250`, `98%`, `12 000`. Разрядный пробел удобно ставить
на шов — тогда зазор Telegram работает как разделитель тысяч.

Две ленты — один механизм, разный набор:

| | 13 | 14 |
|---|---|---|
| Шрифт | Manrope 700, 54 px | Cormorant Garamond 500, 70 px |
| Подчёркивание | есть, кобальт | нет — цифры сами держат строку |
| Разрядный пробел | .24 em | .2 em |
| Где сильнее | мелкий размер, превью чата, цифра как факт | крупный размер, витринный пост, цифра как заголовок |

Serif на 100 px читается хуже гротеска — штрихи Cormorant тоньше, поэтому кегль здесь выше, а
подчёркивание убрано, чтобы не отбирать высоту у самих цифр.

## Фото-набор: венецианская маска

`packs/custom/venetian-mask/` — отдельная пачка, собранная не из вёрстки, а из спрайт-листа:
8×4 = 32 фотографических кадра, трагедия → комедия, PNG с настоящей альфой. Четыре файла:
синий и золотой, каждый в двух режимах.

**Прямой проход** (`-forward`) показывает переход целиком, но на стыке цикла Telegram резко
возвращает маску из комедии в трагедию. **Пинг-понг** (`-pingpong`) доигрывает последовательность
назад — рывка нет, ценой вдвое более быстрой смены мимики.

Пересобирается из `source/` одной командой (исходники хранятся локально, в публичный репозиторий не входят):

```bash
node tools/sprite-to-webm/make.mjs packs/custom/venetian-mask/source/sprite-blue.png pingpong out.webm
```

В общий набор реакций (15–25) этот слой не мешается: рядом с плоскими векторными эмодзи
фотореалистика выбивается, поэтому она живёт отдельной пачкой.

## Кегль и контраст

Эмодзи в списке чатов рисуется в ~24 px, в строке сообщения — в ~20 px. Поэтому:

- Гротеск везде поднят до **700**, Cormorant в 03 — до **500** (R14: для >25pt минимум 400, ставим выше).
- Кегли увеличены на 15–20 %, межбуквенное сжато (`.2em → .12em`) — при том же наборе букв глиф крупнее.
- Внутренние поля плит срезаны с 8/13 px до 4/7 px, у прозрачного режима — почти до нуля.
- `--fx-fg` в тёмной теме подтянут с `#D6D6D2` до `#EFEEEA`, вторичный серый — с `--n500` до `--n300`.

Всё это меняется только в сэндбоксе; токены DS не трогали.

## Экспорт из сэндбокса

Кнопка «Экспорт .webm» кодирует ленты прямо в браузере (WebCodecs + VP9, контейнер EBML собирается
вручную, поэтому длительность ровно 2.967 s и 30 fps на любой машине — почему не 3.000, см. «Длительность») и отдаёт zip с файлами и
`manifest.txt`. Берётся текущее состояние: твой текст, цвета, тема, режим подложки. Нужен Chrome —
в Safari нет ни WebCodecs, ни VP9.

Альфа собирается здесь же: цветовой кадр и альфа-плоскость кодируются двумя VP9-потоками, альфа
уезжает в `BlockAdditional` блока, дорожка получает `AlphaMode 1`. Проверка: `ffprobe` покажет
`alpha_mode: 1`, а `ffmpeg -c:v libvpx-vp9 -i файл -vf alphaextract` вытащит маску.
(`ffprobe` при этом всегда пишет `yuv420p` — это нормально, альфа в VP9 живёт вторым потоком.)

## Рендер скриптом

```bash
node render-webm.mjs                                # с подложкой, тёмная → packs/plate-dark
node render-webm.mjs --plates off                   # альфа, тёмная      → packs/alpha-dark
node render-webm.mjs --plates off --theme light     # альфа, светлая     → packs/alpha-light
node render-webm.mjs premiere like gloss            # только выбранные ленты
node render-webm.mjs rlike reye rspot               # только реакции → packs/reactions/<вариант>
node tools/build-preview.mjs                        # пересобрать preview.html
node tools/fix-duration.mjs packs/reactions          # подрезать длительность уже собранных файлов
node tools/fix-duration.mjs packs --dry              # только показать, что не проходит лимит
```

Скрипт открывает сам сэндбокс в режиме `?stage=<ключ>`, снимает 89 кадров headless-Chrome,
режет их на квадраты 100×100 и кодирует VP9 через ffmpeg с подбором CRF под лимит.
Разница с кнопкой: ffmpeg жмёт лучше при том же весе, поэтому финальные наборы собраны скриптом.

Нужны: Node 18+, Google Chrome, ffmpeg.
ffmpeg берётся из `PATH`, либо из `node_modules/ffmpeg-static` (`npm i ffmpeg-static` в этой папке), либо `FFMPEG=/путь/к/ffmpeg`.
Chrome ищется по стандартным путям, переопределяется через `CHROME_PATH`.

## Файлы

- WEBM / VP9, 100×100, 30 fps, 2.967 s (89 кадров), без звука. 6–48 KB при лимите Telegram 64 KB.
- реакции (`kind:'react'` в реестре) идут не в `packs/<вариант>/<лента>/`, а плоско в
  `packs/reactions/<вариант>/` с одним общим manifest.txt: их грузят пачкой, а не по одной.
  Явный `--out` эту разводку отменяет — всё уходит в указанную папку.
- `noise=alls=2` подмешивается лентам 01, 03, 09 и всем софитам 19–21: без дизеринга VP9 рвёт мягкие градиенты на полосы,
  и так как плитки кодируются независимо, полосы не совпадают — шов становится виден.
- `preview.html` открывает любой набор на трёх фонах (тёмный чат, светлый чат, шахматка) с зазором 0/2/6.

## Какой набор куда

| Набор | Когда |
|---|---|
| `packs/alpha-dark` | канал с тёмной темой, нужен цвет |
| `packs/alpha-light` | канал со светлой темой, нужен цвет |
| `packs/plate-dark` | фон впечатан; годится, когда точно известна тема и хочется плиту как кадр плёнки |
| `packs/reactions/<вариант>` | реакции под постами; вариант выбирается по той же таблице |

Один .webm не подстраивается под тему чата — это видео. Поэтому под разные темы собираются
разные наборы: выбирается файл, а не режим клиента.

## Длительность: почему 89 кадров, а не 90

Telegram для custom emoji требует **WEBM / VP9, 100×100, до 64 KB, до 3 секунд, до 30 fps, с альфой**.
Из этих пяти цифр подводит именно длительность, и подводит незаметно.

90 кадров при 30 fps выглядят как ровно 3.000 s, и поле `Duration` в контейнере честно пишет `3000.000`.
Но последний кадр начинается на 2967 мс и длится ещё 33.3 мс, то есть файл кончается на **3000.3 мс**.
`@Stickers` считает именно конец последнего кадра и отвечает **«This video is too long»** — при том,
что `ffprobe` показывает 3.0 s и файл на глаз выглядит укладывающимся в лимит.

Поэтому наборы собираются из **89 кадров = 2.967 s**, запас 33 мс. Кадр не выбрасывается из анимации:
фаза считается как `f / 89`, полный трёхсекундный цикл раскладывается на 89 кадров и остаётся замкнутым —
меняется только скорость, на 1.1 %, что на глаз не читается.

Уже собранные файлы чинятся без перекодирования:

```bash
node tools/fix-duration.mjs packs/reactions      # папка, рекурсивно
node tools/fix-duration.mjs packs --dry          # посмотреть, ничего не трогая
```

Скрипт выкидывает последний кадр и переписывает `Duration`, а освободившееся место занимает `Void` —
глобальный элемент, который демуксеры пропускают. Байты не сдвигаются, поэтому размеры `Cluster`
и `Segment`, позиции в `SeekHead` и `Cues` остаются верными, вес и качество не меняются.

## Швы

Telegram ставит эмодзи как глифы текста и оставляет между ними зазор ≈ 2 px на плитку 100 px.
Убрать его из файла нельзя: это раскладка клиента. В обычной строке он почти не виден, в jumbo-режиме
(сообщение из одних эмодзи — Telegram увеличивает их в несколько раз) зазор растёт вместе с картинкой.

Что проверено:
- Разрыв внутри наших файлов на стыке — 0.9–1.3 из 255, то есть склейка непрерывна. Виден именно зазор.
- Растушёвка краёв плитки (2 / 6 / 12 px) делает хуже: вместо тонкой линии появляются тёмные полосы-жалюзи.

Отсюда правило вёрстки лент: **шов должен попадать в темноту или в смысловой разрыв.**
- Ничего светлого и тонкого не тянуть через границу 100 px — разложить по плиткам (так сделано в 04: строки билета
  лежат внутри плиток, ни одна не пересекает шов).
- Естественный разрыв композиции ставить ровно на шов (в 04 линия отрыва на x=400 — зазор читается как сам надрыв).
- Гладкие градиенты через всю ленту — худший случай: глазу не за что зацепиться, кроме линии. В 01 луч теперь
  гаснет к дальнему краю, и два дальних шва уходят в темноту.
- Мелкая фактура (пыль, точки, штрихкод) шов прячет, сплошная заливка — подчёркивает.

Кнопки «Швы» и «Зазор → 2px» в сэндбоксе показывают это до рендера.

## Adaptive Color в @Stickers

Режим перекрашиваемых эмодзи: клиент берёт **только форму** (альфа-канал), а цвет подставляет свой.
Всё, что нарисовано внутри файла, отбрасывается — поэтому для наших наборов флаг надо **выключать**:
кобальт и ivory пропадут, а там, где смысл держится на разнице цветов, картинка развалится —
у Switch ползунок сольётся с треком, у Checkbox галочка с заливкой бокса.

## Загрузка

1. `@Stickers` → `/newemojipack` → имя набора.
2. Файлы по порядку имён (`1of5`, `2of5`, …) — порядок в наборе = порядок в ленте.
3. Один эмодзи-алиас на всю ленту (🎭 / ✨ / 🎟) — тогда лента находится в поиске целиком.
4. Ставить кастом-эмодзи может только Premium-аккаунт; у остальных виден статичный первый кадр.
